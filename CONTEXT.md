# LexChain

Legal document backend: a lawyer prepares a document with clients, the signed copy is finalized and its hash anchored on-chain. LexChain does not notarize.

## Language

### Preparation

**Working draft**:
The editable text of a document while it is being prepared, a Google Doc in the lawyer's own Drive. Reference only; the signed copy is the legal document.
_Avoid_: Main file, draft file, Google Doc (as a domain term)

**Draft source**:
Where a working draft's starting text comes from: blank, template (a copy of a Doc), existing (a Doc the lawyer already started), or upload (a file the lawyer brings in, usually one the client handed over).
_Avoid_: Import
